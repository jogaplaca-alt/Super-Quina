# Super Quina

Aplicação web de apostas numéricas com sorteios de cinco algarismos, de 00000 a 99999.

Inclui áreas do jogador, cambista e administrador; apostas numéricas; Pix; carteira; vendas em dinheiro; comissões; recibos digitais/térmicos; consulta pública por QR Code; agendador de rodadas e apuração idempotente.

Branch ativa: setup/super-quina. O projeto original JogaPlacas e sua produção permanecem isolados. Não fazer merge, deploy ou aplicar migrations em banco legado sem autorização explícita.

Consulte MANUAL_TECNICO.md e docs/NUMERIC-GAME-MIGRATION.md antes de promover alterações.
