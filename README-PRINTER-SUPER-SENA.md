# Printer Super Sena

Aplicativo Android dedicado exclusivamente à impressão de comprovantes em impressoras térmicas Bluetooth.

## Estado do projeto
- Baseado no código-fonte reconstruído do RawBT.
- Nome e interface preparados para Printer Super Sena.
- Mantém o pacote Android original `ru.a402d.rawbtprinter` e o esquema `rawbt:` para preservar compatibilidade.
- Não inclui fluxo de vendas, compras ou pagamentos do jogo.
- A remoção completa de telas/licenciamento comercial ainda exige auditoria e teste de compilação.

## Compilação
O workflow **Build Printer Super Sena** espera o arquivo `source.zip` na raiz desta branch. Esse arquivo deve conter a pasta `Printer_Super_Sena/` com o projeto Android. Após adicioná-lo, execute o workflow em Actions.

## Importante
A compilação e os testes em impressora física ainda não foram concluídos.
